Project Breakdown

CosmoPirates was built together with BlackMoon Design as a full commercial PC game, with additional browser demo builds released on portals such as CrazyGames, Newgrounds, and Armor Games. BlackMoon Design created the graphics and co-designed the game. I was fully responsible for programming and contributed to game design, with my work focused on gameplay architecture, technical systems, UI, content workflows, localization tooling, and portal-specific export automation.

Gameplay Architecture

  • Custom ECS structure: designed an ECS-based architecture for a turn-based card battler using Phaser, TypeScript, and Geotic.
  • View-independent simulation: implemented lockstep-style gameplay logic that can run without the visual layer.
  • AI combat testing: built simulations of AI-vs-AI fights to test combat behavior, balance, and edge cases.
  • Procedural maps: used Wave Function Collapse for map generation and repeatable content variation.

UI and Performance

  • Rich Phaser UI: created complex game interfaces directly in Phaser.
  • Pixel-perfect layout: focused on clean presentation, readable screens, and consistent visual alignment.
  • Lightweight font usage: kept text rendering practical and performance-friendly.
  • Separation of systems: kept simulation, game data, and presentation layers independent.

Data-Driven Content Tools

  • Designer-friendly JSON config: built systems where cards and gameplay content can be edited without code changes.
  • Reusable content pipeline: applied the same structure to items, crew members, ships, buffs, dialogue options, and other game data.
  • Translation workflow: created Google Sheets scripts so translators could add languages and export ready-to-use in-game JSON files.

Demo Distribution and Promotion

  • Portal demo builds: released browser demos on CrazyGames, Newgrounds, and Armor Games.
  • Steam funnel: used web demos as promotion channels linking players back to the Steam page.
  • Automated exports: created scripts integrating multiple web game portal APIs, allowing portal-specific demo builds to be generated with one command.

About

I am a game developer focused on commercial PC games and browser/mobile games. I worked as programmer and designer on CosmoPirates, and I have built a catalog of 32 short-session web and mobile games.

All games shown here were built together with BlackMoon Design, which created the graphics and co-designed the projects. I was fully responsible for the programming part and contributed to game design.

I earned a Master of Science in Engineering degree in Electronics and Telecommunications from Poznań University of Technology.

Core tools and technologies include Phaser, TypeScript, ECS architecture, Geotic, Electron, Three.js, Construct 2, Spine, JSON-based content pipelines, localization tooling, and browser portal export automation.
